# Lessons learned

- **Instructions don't widen a role.** A casual request shouldn't let an agent take on work that belongs to someone else.
- **Watchers have to live outside what they watch.** A monitor that fails along with the thing it watches can't help you.
- **Test safety controls, don't assume them.** A sandbox only counts once you've seen it block what it should.
- **Spending needs a hard stop, not a reminder.**
- **Corrections should become rules.** When I correct an agent, the fix gets written down so it doesn't happen again.
